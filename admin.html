Option 1 — Cloudflare Worker (5 min)
Do this once. Fixes extraction error, makes admin fully automatic forever. Free.
1. Sign up free at cloudflare.com
2. Dashboard → Workers & Pages → Create → Create Worker
3. Name it wpt-proxy → Deploy → Edit Code
4. Delete all code. Paste the Worker code from the Setup Guide PDF.
5. Click Deploy → copy the Worker URL (e.g. wpt-proxy.yourname.workers.dev)
6. Worker → Settings → Variables and Secrets → Add → Secret
7. Name: ANTHROPIC_KEY · Value: your Anthropic API key → Deploy again
8. Come back → Settings tab → paste Worker URL → Save
The Worker code to paste is in the Setup Guide. Download it from the Setup Guide file provided.
🐙
Option 2 — GitHub Auto-Publish (10 min)
Do this after Option 1. Adds "Publish to GitHub" button — no more file download/upload.
1. github.com → profile picture → Settings
2. Scroll to bottom → Developer settings
3. Personal access tokens → Tokens (classic)
4. Generate new token (classic)
5. Note: Waikato Prayer Times admin · Expiration: No expiration
6. Scopes: tick repo only → Generate token
7. Copy the token (starts ghp_) — shown once only!
8. Settings tab here → paste token + fill username/repo/path → Save
